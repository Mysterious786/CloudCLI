# Changelog

All notable changes to CloudCLI will be documented in this file.

## [v1.0.0] - 2026-05-02

### 🎉 Initial Release

#### Features
- ✅ Multi-database backup support (MySQL, PostgreSQL, MongoDB, SQLite, Supabase)
- ✅ Cloud storage integration (Backblaze B2, AWS S3, Wasabi)
- ✅ Multi-user authentication system
- ✅ Beautiful interactive CLI with JLine 3
- ✅ Unified shell with single entry point
- ✅ Email notifications (HTML templates)
- ✅ Welcome email on registration
- ✅ Auto-login after registration
- ✅ Backup download functionality
- ✅ Production database support (Supabase/PostgreSQL)
- ✅ Backup compression (gzip)
- ✅ Session persistence

#### Supported Databases
- MySQL
- PostgreSQL
- MongoDB
- SQLite
- Supabase

#### Supported Cloud Storage
- Backblaze B2
- AWS S3
- Wasabi

#### Supported Notifications
- Console
- Email (HTML templates)
- Slack (webhook)
